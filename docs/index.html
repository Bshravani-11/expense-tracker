🎓 Beginner-Friendly Project

💰 Expense Tracker

A modern, full-stack expense tracking web application built with Java Spring Boot and vanilla HTML, CSS & JavaScript. Track your spending in Indian Rupees (₹).

View on GitHub ▶ How to Run
⚠️
This is a Spring Boot application — it requires a local Java server to run

GitHub Pages can only host static websites. Because this app has a Java backend (Spring Boot), the full application must be run locally on your computer. Follow the "How to Run" steps below to launch it at http://localhost:8080.

✨ Features

💸

Monthly Salary Tracker

Set your monthly salary, track spending vs. income, and monitor savings with a visual progress bar and color-coded status badges.

📊

Live Dashboard

Real-time summary cards for Total, Today's, and This Month's expenses, plus the top spending category at a glance.

➕

Add Expenses

Add expenses via a sidebar Quick-Add form or a full modal dialog with amount, category, date, and description.

🔍

Category Filter

Instantly filter transactions by Food & Dining, Transportation, Shopping, Entertainment, Bills & Utilities, Healthcare, and more.

🗑️

Delete with Confirmation

Remove unwanted expenses with a safety confirmation dialog to prevent accidental deletions.

🇮🇳

INR ₹ Formatting

All amounts are displayed in Indian Rupees with proper Indian number grouping (e.g. ₹1,45,000.00).

📈

Category Breakdown

Visual proportion bar and progress meters showing the exact spending amount and percentage for each category.

✅

Validation

Both frontend and backend validate that amounts are positive and all required fields are provided, with clear error messages.

🚀 How to Run Locally (Windows)

1

Clone the repository

Open PowerShell and clone the project to your machine.

git clone https://github.com/Bshravani-11/expense-tracker.git
cd "expense-tracker"
2

Check Java version

Make sure Java 17 or higher is installed. The project was tested with Java 21.

java -version
3

Start the application

Run using the included Maven Wrapper — no installation needed. The app auto-downloads Maven.

.\mvnw.cmd spring-boot:run

Alternatively, double-click run.bat in the project folder, or run the pre-built JAR:

java -jar target\expense-tracker-1.0.0.jar
4

Open in your browser

Once you see "Tomcat started on port 8080", open:

http://localhost:8080

📡 REST API Reference

Base URL: http://localhost:8080/api/expenses

Method Endpoint Description
GET /api/expenses Get all expenses (supports ?category=Food+%26+Dining filter)
POST /api/expenses Add a new expense (JSON body: description, amount, category, date)
DELETE /api/expenses/{id} Delete an expense by ID
GET /api/expenses/summary Dashboard metrics: totals, salary, savings, category breakdown
GET /api/expenses/salary Get currently configured monthly salary
POST /api/expenses/salary Update monthly salary ({"salary": 75000.00})
🗄️
In-Memory Data Store

All expense data is stored in RAM using a thread-safe ConcurrentHashMap. The data resets back to sample expenses each time the server restarts. This keeps the project simple for beginners — connect a database like PostgreSQL or H2 to make data persistent.
